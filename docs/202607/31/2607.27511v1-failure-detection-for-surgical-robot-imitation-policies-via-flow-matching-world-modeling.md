## 摘要
模仿学习在自主机器人手术中展现出越来越大的前景，但由于手术任务的安全关键性以及手术环境的复杂性和变异性，安全部署仍然具有挑战性。因此，故障检测是一项必要的安全保障，但由于故障数据稀缺、操作动态高度多变，以及需要在漏检与破坏性误报之间取得平衡，其开发仍然困难重重。为应对这些挑战，我们提出了FoMo-FD（用于故障检测的流匹配世界模型），一种通过动作条件流匹配世界模型学习名义短时程视觉动态的故障检测方法。FoMo-FD对观测终点潜在表示的逆传输非一致性进行评分，从而无需故障演示即可实现视觉-动作不一致的窗口级检测。检测阈值通过对成功执行进行共形校准获得，在不假设未来故障类型的情况下生成任务特定警报。我们使用达芬奇研究套件（dVRK）在四项手术相关操作任务中评估了FoMo-FD，涵盖模拟和真实世界实验中的二十种故障模式。结果表明，FoMo-FD优于观测级异常基线和同一世界模型的预测误差变体，其中腕部相机视图取得了最强性能，包括在1.3%误报率（FAR）下达到96.6%的故障检测率（FDR）。

## Abstract
Imitation learning has shown increasing promise for autonomous robotic surgery, yet safe deployment remains challenging due to the safety-critical nature of surgical tasks and the complexity and variability of surgical environments. Failure detection is therefore an essential safeguard, but its development remains difficult due to the challenges of scarce failure data, highly variable manipulation dynamics, and the need to balance missed detections against disruptive false alarms. To address these challenges, we introduce FoMo-FD (Flow-Matching World Model for Failure Detection), a failure detection method that learns nominal short-horizon visual dynamics with an action-conditioned flow-matching world model. FoMo-FD scores the inverse-transport nonconformity of observed endpoint latents, enabling window-level detection of visual-action inconsistencies without requiring failure demonstrations. Detection thresholds are obtained by conformal calibration on successful executions, yielding task-specific alarms without assuming future failure types. We evaluate FoMo-FD on four surgically relevant manipulation tasks with twenty failure modes across simulation and real-world experiments using the da Vinci Research Kit (dVRK). Results show that FoMo-FD outperforms observation-level anomaly baselines and a prediction-error variant of the same world model, with the wrist-camera view achieving the strongest performance, including a 96.6% failure detection rate (FDR) at a 1.3% false alarm rate (FAR).

## 二、论文提出的方法论

### 核心思想
- 用**动作条件化的流匹配世界模型**学习名义（正常）短期视觉潜在动态，预测一个短执行窗口的端点潜在状态（endpoint latent），而非逐帧预测。
- 通过**逆传输非一致性评分**（inverse-transport nonconformity scoring）评估观测到的端点潜在是否与学习的名义动态一致，从而识别故障。
- 阈值通过成功 rollout 的**共形校准**（conformal calibration）获得，无需故障数据。

### 技术细节
1. **视觉编码**：
   - 使用冻结的 DINOv2 视觉基础模型提取 patch 特征。
   - 离线训练 β-VAE，将 DINOv2 特征压缩为紧凑潜在张量（16×16×8），训练损失包含重建损失、KL 散度与通道利用率正则项。
   - 推理时使用确定性后验模式 μ 作为潜在表示。

2. **流匹配世界模型**：
   - 输入：潜在视觉历史 Z_t（长度 L=4）与后续指令动作块 A_t（长度 K=4），构成条件上下文 c_t。
   - 目标：预测窗口端点潜在 z_{t+K} 的条件分布，训练目标为匹配线性路径上的目标速度场（flow matching loss）。
   - 架构：视图特定分支 + 共享动作条件器；使用 Transformer 骨干，包含时间注意力、空间注意力、动作 token 交叉注意力与全局动作调制（adaptive modulation）。
   - 附加辅助损失：单步潜在预测损失用于特征正则化（仅训练时使用）。

3. **非一致性评分与检测**：
   - 测试时将观测端点 z_t 作为 x_1，沿学习到的流场 ODE 反向积分到 τ=0，得到逆传输变量 ε̂（应接近高斯基底分布）。
   - 分数 r_t = ||ε̂_t / σ||²，分数越高表示观测视觉转换越不符合名义动态。
   - 共形校准：在 N 个成功 rollout 上取峰值分数，按分位数设置阈值 λ，误覆盖率 α=0.05。

4. **训练损失**：L_total = λ_FM L_FM + λ_aux L_aux（实验中 λ_FM=1.0，λ_aux=0.5）。

## 六、论文的主要结论与发现

1. **FoMo-FD 优于所有基线**：WM-NC 在总体 FDR 和 FAR 上均优于 WM-PE、logpZO 和 RND。
2. **逆传输评分优于预测误差**：同一世界模型下，WM-NC（96.6% FDR）显著优于 WM-PE（52.2% FDR），说明逆传输非一致性比直接预测误差更具判别力。
3. **腕部视角显著优于固定视角**：腕部 WM-NC 达到 96.6% FDR / 1.3% FAR；固定视角仅为 45.9% FDR / 10.0% FAR。局部工具-组织交互视图对操纵故障检测更为有效。
4. **动作条件化是关键**：动作 token 交叉注意力 + 全局调制的组合（96.6% FDR）优于无动作条件（87.2% FDR），且主要增益体现在腕部视角。
5. **端点预测地平线影响显著**：K=4 时腕部 FDR 达 96.6%，K=1 时仅 42.2%，说明较长的窗口允许偏差累积为可检测的不一致。
6. **与高层监控互补**：FoMo-FD 检测“交互是否按名义动态展开”，与任务进度型 VLM 监控器互为补充。


## 七、优点

### 方法设计
- **无需故障示范**：仅用成功数据训练与校准，突破故障数据稀缺瓶颈，契合临床可大规模获取常规成功手术数据的特点。
- **窗口级动态建模**：区别于逐帧观测级异常检测，捕捉时序演化异常，针对“单帧正常但转换异常”的故障类型更有效。
- **逆传输评分**：将观测端点按名义动态“倒带”回基底分布，直接度量实现与命令的一致程度，比预测误差更有判别力。
- **共形校准**：提供统计可解释的任务特定阈值，不假设故障类型或时序。
- **可在线运行**：13.98 Hz 的评分频率超过策略频率，有在线部署潜力。

### 实验设计
- 覆盖仿真+真实双平台、动作执行与感知异常多种故障类别，消融实验设计清晰，基线控制在相同特征/校准条件下，结论可靠性高。


## 八、不足与局限

### 实验覆盖
- 真实实验每故障模式仅 10 个样本，统计功效有限。
- 未进行多视角融合实验（虽列为未来工作）。

- 故障模式的“人为注入”可能与真实自然故障分布存在差异。

### 方法层面的局限
- **仍需成功策略 rollout 进行校准**：虽然不需要故障数据，但需要部署策略分布下的成功 rollout 以支持共形校准的交换性假设；在策略迭代更新后可能需要重新校准。
- **固定阈值而非时变阈值**：未采用 FAILDetect 中的时变共形带；手术任务中不同 rollout 到达同一任务阶段的时间不一致，固定阈值可能不够自适应。
- **低层执行监控为主**：不处理任务进度类故障（如策略一致但任务无进展），与 Sentinel 中 task-progression failure 的区分中只覆盖前一种。

### 偏差与泛化风险
- 使用单一手术平台（dVRK）与有限任务子集，泛化到更广泛手术类型仍有待验证。
- DINOv2 与 VAE 特征可能对训练分布外的视觉域（如不同内窥镜、光照条件）敏感。
- 世界模型训练仅用专家示范，但部署时策略分布可能偏移，对检测性能的影响未充分分析。

### 其他
- 未报告训练时长、GPU 数量等训练算力细节。
- 所有检测实验为离线推演，未在真实闭环场景中验证检测-干预联动效果。
