## 摘要
可供性引导的模仿学习通过将视觉感知压缩为任务特定的几何约束（如固定接触点），在机器人操作任务中展现了卓越的性能。然而，常用的静态可供性在精度关键任务或物体位置扰动下可能变得不一致，导致接触后轨迹漂移。为解决这一问题，我们提出AffordTrajDP，一种动态框架，通过以物体为中心的时间传播构建可供性轨迹，以引导渐进式操作过程。具体而言，给定RGB-D观测，我们的核心洞察是：检索到的锚定可供性（捕捉末端执行器与目标物体之间期望接触点）可以通过可供性传播，利用物体的SE(3)位姿作为自然传播媒介向前传播，从而生成在整体执行过程中提供时间一致、状态感知引导的可供性轨迹。AffordTrajDP在ManiSkill3上实现了70.0%的平均成功率，比强基线高出最多17.8%。在Galaxea A1和UR7e机械臂上的真实世界实验，涵盖StackCube、PickCup、AdapterInsertion、Ring-on-Peg、Put-in-Bowl和USB Insertion，进一步验证了在物体位置变化和外观变化下的鲁棒性，并在Galaxea A1上评估了见过和未见过的物体实例，消融实验确认了每个提出组件的贡献。

## Abstract
Affordance-guided imitation learning has shown impressive performance in robotic manipulation tasks by compressing visual perception into task-specific geometric constraints (e.g., fixed contact points). However, the commonly used static affordances can become inconsistent in precision-critical tasks or under object location perturbations, leading to post-contact trajectory drift. To address this issue, we propose AffordTrajDP, a dynamic framework that constructs affordance trajectories via object-centric temporal propagation to guide the progressive manipulation process. Specifically, given an RGB-D observation, our core insight is that a retrieved anchor affordance, which captures the desired contact point between the end-effector and the target object, can be propagated forward via affordance propagation, using the object's SE(3) pose as a natural propagation medium, to yield an affordance trajectory that provides temporally consistent, state-aware guidance throughout execution. AffordTrajDP achieves 70.0% average success rate on ManiSkill3, outperforming strong baselines by up to 17.8%. Real-world experiments on Galaxea A1 and UR7e robotic arms, covering StackCube, PickCup, AdapterInsertion, Ring-on-Peg, Put-in-Bowl, and USB Insertion, further validate robustness under object placement variations and appearance changes, with seen and unseen object instances evaluated on Galaxea A1, and ablations confirm the contribution of each proposed component.

## 1. 核心问题与整体含义（研究动机与背景）

- **背景**：视觉运动策略（如 Diffusion Policy、3D Diffusion Policy）依赖密集视觉观测，对环境扰动（物体外观、背景布局）敏感，泛化能力受限。为此，现有工作引入物体中心表示，其中 **affordance（可供性）** 编码任务相关的交互先验（如接触点、接触后运动），被证明是一种有效的结构化中间表示。
- **核心问题**：现有 affordance 引导方法（如 AffordDP）将 affordance 视为**静态先验**——一旦通过一次性刚性变换从参考演示转移到目标场景，在整个回合中保持固定。在**精度关键任务**（如插接）或**物体位姿扰动**下，物体接触后会发生移动，静态接触点无法跟踪物体演化后的位姿，导致“接触后轨迹漂移”，引导信号逐渐失效。
- **本质诊断**：以往的条件信号只“各取一半”——有的跟踪物体全局位姿（当前帧或未来轨迹）但丢失“接触何处”的语义；有的检索语义接触点但丢失“接触点应随物体移动而如何更新”。缺少**同时保留两者**的单一信号是精度关键失败的根源。
- **整体含义**：论文提出**动态 affordance 轨迹**的新范式，将静态接触点沿物体 SE(3) 位姿轨迹传播，生成时间一致、状态感知的引导信号，从而解决静态先验漂移问题，提升精确操作与泛化能力。

## 2. 方法论：核心思想、关键技术细节与流程

### 2.1 核心思想
- 利用检索得到的**锚定 affordance（3D 接触点）**，结合预测的物体**未来 SE(3) 位姿轨迹**，通过刚性变换将接触点沿时间轴传播，生成一条**动态 affordance 轨迹**，作为扩散策略的条件信号。
- 关键设计：物体位姿轨迹只在**物体自身坐标系**中表达（消除绝对场景布局差异），提高跨实例泛化能力；条件信号同时编码“接触哪里”（语义锚点）与“如何演化”（位姿传播）。

### 2.2 技术流程（Pipeline）
1. **锚定 affordance 生成（Anchor Affordance Generation）**：
   - 使用 Grounded-SAM 分割物体区域，CLIP 图像编码器提取外观特征，构建物体记忆库 M = {(ℓ, c, z, T)}，其中 ℓ 为任务标签、c 为静态接触点、z 为外观特征、T 为 RGB-D 位姿估计。
   - 测试时，在同一任务内按 CLIP 余弦相似度检索最近邻源物体；通过源-目标稠密视觉对应，将源接触点转移到目标物体上，得到锚定接触点 c_tgt ∈ R³。
   - 选择**检索而非回归**，是因为接触区域往往是小而稀疏的表面区域，直接回归容易与其他显著但无关的几何特征混淆。

2. **未来位姿估计（Future Pose Estimation）**：
   - 演示阶段：Grounded-SAM 分割物体 → Any6D 重建网格 → FoundationPose 跟踪 6D 位姿，得到物体位姿轨迹 T(t) ∈ SE(3)。
   - 将源物体位姿表达在目标物体坐标系下：T_src_tgt(t) = (T_tgt_W(t))⁻¹ · T_src_W(t)，得到布局无关、物体居中的轨迹，作为轨迹扩散模型的训练监督。
   - 轨迹扩散模型使用 **DDIM**（而非 DDPM），其采样轨迹确定性高、可大幅减少去噪步数，避免每步随机扰动传播到 affordance 轨迹，并降低推理延迟。

3. **动态 affordance 传播（Affordance Propagation）**：
   - 轨迹扩散模型以位姿历史 h_t 为条件，预测未来 H 步 SE(3) 位姿 {T_{t+k}}。
   - 将锚定接触点经刚性变换传播：p_{t+k} = T_{t+k} · c̃，其中 c̃ 为 c_tgt 的齐次坐标，得到动态 affordance 轨迹 τ = [p_t, …, p_{t+H}]，最终条件信号 Φ = (c_tgt, τ_tgt)。

4. **动作生成（Action Generation）**：
   - 静态接触点用轻量 MLP 编码；动态轨迹用 Transformer（带 [CLS] token + 位置编码）编码。
   - 二者与点云观测、本体感觉共同构成条件特征 f_t，输入 DDIM 去噪网络，从高斯噪声中迭代去噪生成动作序列，按 receding-horizon 方式执行（预测 16 步，执行前 8 步，10 Hz）。

## 3. 实验设计：数据集、场景与对比方法

### 3.1 仿真实验（ManiSkill3）
- **任务**：6 个桌面操作任务——PickCube、StackCube、PegInsertion、PlugCharger、PokeCube、PushCube，覆盖低到高精度的接触模式。
- **机器人**：Franka Panda + 平行夹爪。
- **演示数量**：PickCube/StackCube/PokeCube/PushCube 各 30 条；PegInsertion/PlugCharger 各 50 条。
- **对比基线**：DP3（纯点云）、AffordDP（DP3 + 静态接触点）、SPOT（预测未来 SE(3) 位姿轨迹并直接条件化策略）。所有方法共享相同演示与超参数。

### 3.2 真实世界实验
- **平台一**：Galaxea A1 + RealSense L515，任务为 StackCube、PickCup、AdapterInsertion，每个任务训练单一统一策略（30 条遥操作演示），在**已见/未见物体实例**上各测试 30 次。
- **平台二**：UR7e + RealSense D455，任务为 PickCup、Ring-on-Peg、Put-in-Bowl、USB Insertion，各测试 30 次，对比 DP3、AffordDP、SPOT。
- **消融实验**（Galaxea A1）：DP3、DP3+Center（物体中心）、DP3+Contact（静态接触点）、DP3+Traj（仅位姿轨迹，无语义锚点）、Ours（接触点 + 传播轨迹），共 180 trials/方法。

## 6. 主要结论与发现

- **动态 affordance 轨迹显著优于静态先验**：ManiSkill3 平均成功率 70.0%，比 DP3（52.2%）、AffordDP（57.8%）、SPOT（62.1%）分别高出 17.8、12.2、7.9 个百分点；在 PegInsertion 和 PlugCharger 等精密插接任务上提升最大。
- **真实世界跨平台验证**：Galaxea A1 平均成功率 66.1%（基线 DP3 仅 35.0%）；UR7e 平均 72.5%（DP3 40.8%、AffordDP 55.8%、SPOT 54.2%）。在精度最苛刻的 AdapterInsertion 和 USB Insertion 上，动态引导带来的增益最突出（但 USB 仍仅 11/30，暴露精度边界）。
- **“各自必要，单独不足”是可证伪结论**：消融显示，仅加静态接触点（+Contact）比仅加中心点有提升但在低水平平台期；仅加位姿轨迹（+Traj）在 StackCube unseen 上退化至 20%（低于基线 40%），因为无语义锚定会引入噪声；只有两者结合（Ours）才稳定产生大幅增益。
- **预测误差不随时间累积**：位姿预测误差在每个 episode 步上大致保持平稳，只在接触事件附近出现可衰减的旋转误差尖峰；FoundationPose 跟踪误差在接触后升高，提示真实瓶颈可能在上游跟踪噪声而非预测误差的复合。

## 7. 优点

- **问题定义新颖且清晰**：明确指出了静态 affordance 在接触后漂移的根本缺陷，并形式化为“同时保留何处接触与如何演化”的联合条件信号缺失问题。
- **方法设计合理**：检索而非回归接触点，规避小区域定位困难；物体中心坐标系消除场景布局差异；DDIM 保证采样确定性与低延迟；模块解耦（检索、位姿扩散、传播、动作生成），便于消融验证。
- **消融实验有判别力**：+Center、+Contact、+Traj、Ours 的四级对比，不仅证明“方法有效”，还验证了两种组件独立不足、组合必要的因果关系，而非简单的模块堆叠。
- **评估范围广**：仿真 + 双真实平台 + seen/unseen 实例，跨机械臂、相机、任务几何，增强了结论的可泛化性；对位姿预测误差做了细粒度的时间步分析，提供了诊断性证据。
- **诚信度高**：作者主动声明位姿误差分析非受控消融，并把更强论断列为假说，体现科学严谨性。

## 8. 不足与局限

- **算力信息缺失**：未报告 GPU 型号、数量、训练时间等，影响复现与横向成本对比。
- **真实实验规模有限**：每任务仅 30 trials，统计噪声不可忽视（例如 StackCube seen 上 +Center 略高于 +Contact 即被作者归因于 30-trial 噪声）；每任务仅 30 条演示，样本效率声明缺乏更细粒度验证。
- **精度边界暴露**：USB Insertion（11/30）和 AdapterInsertion unseen（6/30）成功率仍偏低，说明方法在亚毫米级精度、深度遮挡场景下仍受限于底层跟踪感知（FoundationPose 在接触后误差升高）。
- **基线覆盖不全**：未与 AnchorDP3、FSAG、Learning from 10 Demos 等更近期工作比较；SPOT 的实现是否完全公平（如是否使用了相同位姿估计管线）未详述。

- **应用限制**：依赖多阶段感知管线（Grounded-SAM 分割、CLIP 检索、Any6D 重建、FoundationPose 跟踪、稠密对应），各模块误差会级联，在重遮挡、透明物体或快速运动场景下稳定性存疑；静态接触点的“一次性转移”在物体形变或非刚性变化下仍有局限。
