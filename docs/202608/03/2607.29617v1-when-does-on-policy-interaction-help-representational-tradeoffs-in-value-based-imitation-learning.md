## 摘要
模仿学习（IL）——训练智能体从演示中复制专家行为——支撑着从机器人技术到语言模型训练的应用。众所周知，标准方法如行为克隆（BC）会受到复合误差和性能瓶颈的影响，特别是当学习者无法完美表示专家策略时（这在例如蒸馏中很常见）。两种干预措施在经验上被广泛认为能提升性能：在学习者自身轨迹上交互式地查询专家，以及在生成策略的过程中使用价值函数估计，而不是直接拟合专家的完整动作分布。我们研究了这些改进的性质及其可能令人惊讶的相互作用。我们的主要发现是，专家交互放宽了学习者的表示需求：只需一个能够实现专家价值函数的模型，绕过了实现专家策略本身这一（通常更严格的）要求。具体而言，我们引入了OVI，一种交互式在线策略IL算法，只要学习者能表示专家的价值函数，它在统计上就是高效的，并且在给定线性最大化预言机的情况下计算上也是高效的。我们补充了一个否定结果，表明交互是必要的。也就是说，在仅满足专家价值可实现性而没有更强假设的情况下，任何离线IL算法都必须随专家策略类的复杂度而扩展。我们的发现在经验上得到了证实。OVI优于基于离线策略的方法（BC）、交互式基于策略的方法（DAgger）和基于离线价值的IL方法，当学习者网络的表达能力远低于专家时提升最大。

## Abstract
Imitation learning (IL)---training an agent to replicate expert behavior from demonstrations---underpins applications from robotics to language model training. Standard approaches such as Behavior Cloning (BC) are known to suffer from compounding errors and performance plateaus, particularly when the learner cannot perfectly represent the expert's policy (as is typical, e.g., in distillation). Two interventions are widely understood empirically to improve performance: querying the expert interactively along the learner's own trajectories, and using value function estimation en route to generating a policy rather than directly fitting the expert's full action distribution.   We investigate the nature of these improvements and their potentially surprising interplay. Our main finding is that expert interaction relaxes the representational demands on the learner: one only needs a model capable of realizing the expert's value function, bypassing the (often stricter) requirement of realizing the expert's policy itself. Concretely, we introduce OVI, an interactive on-policy IL algorithm that is statistically efficient whenever the learner can represent the expert's value function and computationally efficient given access to a linear maximization oracle. We complement this with a negative result showing that interaction is necessary. Namely, without stronger assumptions beyond expert-value realizability alone, any offline IL algorithm must scale with the complexity of the expert policy class. Our findings bear out empirically. OVI outperforms offline policy-based (BC), interactive policy-based (DAgger), and offline value-based IL methods, with the largest gains when the learner network is substantially less expressive than the expert's.

## 2. 方法论

### 2.1 核心思想

- 在**性能差异引理**的基础上，将模仿学习的次优性差距表示为“优势函数”的求和：
  \[
  J^{\pi_E} - J^{\pi} = \sum_{h=1}^H \sum_{x} d^{\pi}_h(x) \langle Q^{\pi_E}_h(x,\cdot), \pi_{E,h}(\cdot|x) - \pi_h(\cdot|x) \rangle
  \]
- 将目标转化为一个**min-max博弈**：π-player 和 Q-player 交替优化，等价于“On-Q”矩匹配框架。
- 关键设计：**逐层（layer-wise）学习策略**，即先固定前 h 层的输出策略，再学习第 h 层的策略。这样每个阶段的采样分布 \(d^{\pi_{out}}_h\) 在优化该层前已经固定，便于构造统计高效的估计。

### 2.2 OVI 算法（Algorithm 1）

| 步骤 | 操作 |
|---|---|
| 1 | 初始化：学习率 \(\eta\)、迭代数 \(K\)、每阶段专家查询数 \(n_E\) |
| 2 | 外层循环 \(h=1,\dots,H\)：采集状态 \(x^i_h \sim d^{\pi_{out}}_h\)，查询专家动作 \(a^i_{E,h} \sim \pi_{E,h}(\cdot\|x^i_h)\) |
| 3 | 初始化 π-player 为均匀分布 |
| 4 | 内层循环 \(k=1,\dots,K\)：Q-player 对经验目标做最佳响应（线性最大化 oracle）；π-player 做软max（指数梯度）更新 |
| 5 | 输出策略为迭代平均：\(\pi_{out,h} = \frac{1}{K}\sum_k \pi^k_h\) |

### 2.3 理论保证

- **Theorem 3.1**：在有限类 \(\mathcal{Q}\) 满足 \(Q^{\pi_E}\) 可实现性假设下，OVI 的专家查询复杂度为：
  \[
  \tilde{O}\left(\frac{H^5 Q_{\max}^4 \log(A) \log(|\mathcal{Q}|/\delta)}{\varepsilon^4}\right)
  \]
- 统计复杂度仅随价值函数类的对数基数增长，**不依赖学习者策略类的复杂度**。
- 在 \(\mathcal{Q}\) 为凸时，查询复杂度可改进为 \(\tilde{O}(\varepsilon^{-2})\)。
- 计算上仅需标准线性最大化 oracle 和 softmax 策略更新。

### 2.4 配套否定结果

- **Theorem 3.2（奖励可实现性不足）**：仅凭奖励函数可实现性，即使允许交互，任何算法也需 \(\Omega(|\mathcal{X}|/\varepsilon)\) 轮交互，说明 \(Q^{\pi_E}\) 可实现性是最小化假设。
- **Theorem 4.1（交互必要性）**：仅凭 \(Q^{\pi_E}\) 可实现性，任何离线 IL 算法的样本复杂度必须随状态数或专家策略类复杂度线性增长。
- **Theorem 4.2（VI 策略类不可辨识性）**：对输出价值诱导策略的离线算法，即使在无限数据下也无法保证低于常数级误差。

## 6. 主要结论与发现

1. **交互式学习能显著放松表示需求**：学习者在只满足 \(Q^{\pi_E}\) 可实现性（而非策略可实现性或完整价值类闭包）时，仍可通过交互获得高效保证。
2. **交互是必要的**：在 \(Q^{\pi_E}\) 可实现性这一最弱自然假设下，离线 IL 算法无法摆脱对状态数或策略类复杂度的依赖。
3. **OVI 在实证上优于所有基线**：当学习者网络远小于专家时（策略可实现性被破坏的区间），OVI 优势最大。
4. **价值驱动与策略匹配的机制差异**：OVI 追求匹配专家回报而非专家轨迹分布，因此在学习效率上显著优于 DAgger。
5. **链式思维（CoT）学习的计算收益**：OVI 可将对完整响应空间的搜索分解为逐 token 的策略更新，避免了指数级复杂的序列级奖励优化。

## 8. 不足与局限

- **样本复杂度对 H 的依赖**：OVI 的查询复杂度是 \(\tilde{O}(H^5/\varepsilon^4)\)，相对基于策略的方法（如 BC 在策略可实现时可达 \(\tilde{O}(H^2/\varepsilon^2)\)）有较大差距，作者也坦承是否有改进空间是开放问题。
- **非凸价值类的统计效率**：OVI 在非凸 \(\mathcal{Q}\) 下是 \(\tilde{O}(\varepsilon^{-4})\)，统计上更优的 Q-OVI 需要离散化价值类，计算上不可行。
- **实验范围有限**：仅涉及 Gymnasium 控制任务；缺乏高维、大规模（如语言模型）实验验证实际有效性。
- **交互预算的计量**：论文中交互方法的“每轮轨迹标记”与离线方法使用的“专家轨迹数”虽对齐，但在实际部署中，交互成本通常远高于离线数据。
- **缺少对噪声或近似误差的鲁棒性分析**：仅讨论精确可实现性，对价值函数设定误差（misspecification）情形未展开。
- **VI 策略类下界的具体性**：Theorem 4.2 的否定结果对这一特定策略类成立，但更广义的基于价值策略（如行为克隆加价值正则化）是否同样失效未完全覆盖。
