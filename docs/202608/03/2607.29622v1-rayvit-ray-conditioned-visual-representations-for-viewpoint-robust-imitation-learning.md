## 摘要
视觉模仿学习使机器人能够直接从图像中获取视觉运动技能，然而RGB观测缺乏显式几何线索，导致所学策略对相机扰动脆弱。为解决此问题，我们提出了RayViT（光线条件视觉Transformer编码器），一种轻量级架构，将相机几何注入预训练的ViT骨干网络。RayViT将相机几何表示为Plücker光线图，将其分块为光线特征，并使用门控交叉注意力生成光线条件类标记。这些光线特征作为密集位置嵌入添加，而光线类标记则取代原始ViT类标记以提供几何感知的摘要表示。我们将此方法与辅助余弦相似度损失结合，以一致地提升几何感知标记的性能和鲁棒性。在模拟和真实机器人任务上的实验表明，在多任务RoboCasa基准的相机扰动下，RayViT相比基线将鲁棒性提升了约13个百分点，在真实世界多任务成功率方面平均完成了1.78个额外阶段。

## Abstract
Visual imitation learning enables robots to acquire visuomotor skills directly from images, yet RGB observations lack explicit geometric cues, making learned policies brittle to camera perturbations. To address this, we propose \textbf{Ray-conditioned Vision Transformer Encoder (RayViT)}, a lightweight architecture that injects camera geometry into pretrained ViT backbones. RayViT represents camera geometry as a Plücker ray map, patchifies it into ray features, and uses gated cross-attention to produce a ray-conditioned class token. These ray features are added as dense positional embeddings, while the ray class token replaces the original ViT class token to provide a geometry-aware summary representation. We combine this approach with an auxiliary cosine similarity loss to consistently improve the performance and robustness for geometry-aware tokens. Experiments on sim- and real-robot tasks demonstrate that RayViT improves robustness by approximately 13 percentage points under camera perturbations in multi-task RoboCasa benchmark and by 1.78 average completed stages in real-world multi-task success rate compared to baselines.

# RayViT 论文详细中文总结

## 1. 论文的核心问题与整体含义

视觉模仿学习使机器人能够直接从人类演示的 RGB 图像中习得视觉运动技能，但 **RGB 观测缺乏显式的 3D 几何线索**，导致策略对相机位姿变化（如平移、旋转）极为敏感。其根源在于：预训练视觉编码器（如 DINOv3）编码的是场景外观语义，却对"相机与世界的几何关系"一无所知，因此策略容易学习到"视角特定的表观-动作映射"，而非"视角不变的场景-任务表示"。当测试时相机被移动或遮挡后重新布置时，策略性能会骤降。

已有解决方案存在明显短板：
- **多视角数据增强**方法（如采集多相机演示、合成新视角）虽有效，但采集成本高、难以扩展到真实世界；
- **显式 3D 表示**方法（如点云、点图）提供了几何信息，但需要额外深度传感器或重建流程，且与基于纯图像先验的现代视觉基础模型难以直接兼容。

本文的核心主张是：**无需额外传感器或多视角增强，仅通过向预训练 ViT 中注入相机内外参所编码的轻量几何线索（Plücker 射线图），即可显著提升视觉模仿策略对相机扰动的鲁棒性。**

## 2. 论文提出的方法论

### 2.1 核心思想

将相机几何编码为与图像逐像素对齐的 **Plücker 射线图**（ray map），并通过两种互补的注入机制嵌入预训练 ViT 的 token 流中；同时引入跨视图一致性辅助损失，使几何感知的表示在不同视角下趋于一致。

### 2.2 关键技术细节

1. **Plücker 射线图建模**
   - 对像素 \( p=(u,v,1)^\top \)，计算世界系下的相机中心和射线方向：
     \( o_w = -R^\top t,\quad d_w(u,v) = \frac{R^\top K^{-1}p}{\|R^\top K^{-1}p\|_2} \)
   - 射线编码为六维向量 \( r(u,v) = [d_w(u,v),\ m_w(u,v)] \in \mathbb{R}^6 \)，其中力矩 \( m_w = o_w \times d_w \)；
   - 所有像素的射线向量构成射线图，与 RGB 图像空间对齐，仅需相机内参 K 和外参 (R,t)，不依赖任何额外传感器。

2. **Patch 对齐射线特征作为位置嵌入**
   - 使用**平均池化**（无参数，保留几何语义）将射线图下采样至 ViT patch 分辨率；
   - 经两层 MLP（GELU 激活）投影到编码器隐层维度，作为**外加的、与图像 patch 一一对应的绝对 3D 位置嵌入**，在输入第一个 Transformer 块之前加到 patch token 上；
   - **保留原始旋转位置编码 RoPE 不变**：RoPE 提供图像平面内的局部空间推理，射线特征提供相机相关的绝对几何锚定，二者互补。

3. **射线条件类标记（Ray-conditioned Class Token）**
   - 标准 ViT 的 [CLS] 是自由参数，只能从图像 patch 间接获取几何信息；
   - RayViT 引入一个可学习的 query token，通过**两个门控交叉注意力块**（参考 Qwen）交叉关注 patch 对齐射线特征，逐步把相机几何聚合成单个 token；
   - 注意力后施加**逐元素可学习的 sigmoid 门控**，以自适应调节几何条件的强度，避免破坏预训练表示分布；
   - 最终输出作为光线条件类标记，**替代原始 [CLS] token** 送入后续 Transformer 层。

4. **跨视图一致性目标（Cross-view Alignment Objective）**
   - 在中间层（默认第 10 层）提取各类视角的类标记，利用**余弦相似度损失**令非参考视角与参考视角（以手部相机视图为锚点）对齐；
   - 总损失：\( L = L_{\text{IL}} + \lambda L_{\text{cos}} \)，默认 \( \lambda=0.01 \)；
   - 该损失仅作为辅助正则项。作者发现：**该目标只有在 token 已具备几何信息时才有效**（作用于纯 RGB 基线不会稳定提升性能）。

## 3. 实验设计

- **模拟实验**：基于 **RoboCasa** 基准，选取 **16 个任务**（涵盖物品搬运、开/关抽屉、开关炉灶、水龙头操作、咖啡制作等多类操作技能），采用多任务学习设置（单个策略同时学习 16 个任务）。每个任务 50 条人类演示，训练 50 epochs、3 个随机种子，取第 30/40/50 epoch 的最优 checkpoint 评估，每任务 50 个 episode。
- **真实机器人实验**：Franka Panda 7-DOF 机器人上完成 **4 个长时程任务**（Drawer 抽屉、Insertion 插入、Pick Place 抓放、Cup Stack 叠杯）。三相机视觉系统（左、右、手部），显式替换右侧相机位姿构成扰动 variant。共采集 50 条（3 个任务）或 100 条（Insertion）语言条件演示，每任务 20 次 rollout。
- **评估设置**：在训练相机设置（Default）与随机旋转/平移后的扰动相机设置（Variant）下分别评估，报告成功率或分阶段完成得分。
- **对比方法**：
  - **Adapt3R**：预训练 2D 语义特征 + 3D 点云定位，需要深度传感器；
  - **PMP-xyz / PMP**：显式 3D 点图表示，PMP 额外融合 2D 语义 token；
  - **CamPose**：同样使用射线图，但作为额外输入模态在后期拼接到语义特征；
  - **RGB**：图像-only 的自身变体，无任何射线图条件化；
  - 自身两个变体：**RayViT-cls**（仅类标记注入几何）与 **RayViT**（类标记 + patch 级射线位置嵌入）。
- **公平性保证**：所有方法使用相同的基于 score 的扩散策略 + decoder-only xLSTM 动作头，视觉编码器均端到端全量微调，排除了策略架构差异的干扰。

## 6. 论文的主要结论与发现

1. **RayViT 在相机扰动下显著优于基线**：
   - 模拟中，RayViT 在扰动设置下平均成功率 37.3%，比 RGB 基线（24.0%）高 **13.3 个百分点**；性能下降幅度仅为 2.5%，远小于 RGB 的 18.5%；
   - 真实实验中，RayViT 在扰动设置下平均完成阶段比 RGB 高 **1.78 个阶段**（2.69 vs 0.91），且性能降幅最小（-0.12）。

2. **几何注入的两种机制各有作用**：仅类标记条件化（RayViT-cls）已显著提升鲁棒性（性能降幅从 18.5% 降至 6.2%），再加入 patch 级射线位置嵌入（RayViT）进一步降低到 2.5%。

3. **余弦一致性损失的生效前提是几何感知表示**：该损失在 RayViT/RayViT-cls 上始终带来一致提升，但在纯 RGB 编码器上无法稳定改善性能。

4. **深层应用辅助损失效果更好**：第 10 层应用显著优于较早层（6-8 层）。

5. **优势不依赖预训练**：从零训练时 RayViT 仍比纯图像表示鲁棒性更好（降幅 2.9% vs 19.2%）。

6. **跨骨干有效**：在 DINOv3 和 EUPE 两种预训练 ViT 骨干上均能带来一致性收益。

7. **直接注入优于后期融合**：CamPose 同样使用射线图但选择后期拼接，无论在默认还是扰动设置下均明显落后于 RayViT。

## 7. 优点

1. **轻量且即插即用**：新增参数仅约 4M，可与任意预训练 ViT 兼容，完全端到端微调，无需两阶段训练流程。
2. **无需额外传感器/重建**：仅依赖相机内参和外参标定（多数方法本来就要求标定），避免了点云/深度图的噪声与尺度问题。
3. **对预训练特征分布干扰小**：门控交叉注意力与加法注入的设计尽量保持原 ViT 注意力行为，配合保留 RoPE，兼顾了预训练语义先验与新注入的几何信息。
4. **洞察深刻**：发现"跨视图一致性损失仅在几何感知表示上有效"这一现象，揭示了几何锚定对辅助表征学习的前提性作用，方法论上有启发价值。
5. **验证体系较完整**：模拟 + 真实、多任务、多基线、多种消融（损失函数、注入层、是否预训练、是否更换骨干），证据链相对严谨。
6. **鲁棒性提升幅度大且稳定**：模拟与真实实验中均呈现一致的趋势，且性能下降幅度大幅收窄。

## 8. 不足与局限

1. **骨干类型受限**：仅针对 ViT 架构设计，未覆盖强大的卷积类视觉编码器，适用范围存在边界。
2. **依赖多视角与锚点选择**：余弦一致性损失需要多视图设置，且在实验中依赖"手部相机视图"这一任务相关的锚点；若任务中没有此类较优视角，或仅存单视角，目标函数的设计需要重新考虑。
3. **未深入研究视角数量的影响**：论文在固定数量（3 个视角）下验证，对稀疏视角（1-2 个）或密集多视角场景下的表现缺乏讨论。
4. **真实实验规模较小**：4 个任务、单种机器人、单一操作场景，且各任务 20 次 rollout 的统计功效有限；真实环境没有对比外部基线（如 Adapt3R、PMP），削弱了"真实世界优于现有方法"的结论强度。
5. **外参标定要求**：射线图需要世界系下的相机外参，虽然比多数 3D 方法要求的深度传感更低门槛，但对外参标定误差的敏感性并未单独分析。
6. **模拟与真实分辨率的差异**：论文提到真实图像分辨率是模拟的两倍，patch 序列更长，两种环境下 RayViT-cls 与 RayViT 的相对优劣出现不一致（真实中 RayViT 更好），说明注入机制的最优形式可能与输入分辨率/序列长度有关，需进一步探究。
7. **缺少对扰动幅度上界的刻画**：实验仅报告了随机扰动范围内的平均表现，未系统扫描不同扰动幅度下的性能衰减曲线，因而难以估计方法的鲁棒性边界。
