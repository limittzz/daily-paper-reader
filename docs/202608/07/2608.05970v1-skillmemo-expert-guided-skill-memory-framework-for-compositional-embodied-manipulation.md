## 摘要
具身视觉运动模型，包括扩散策略（DP）和视觉-语言-动作（VLA）模型，在机器人操作基准测试中展现出了良好的性能。然而，其潜力从根本上受限于大规模具身轨迹数据的稀缺性，导致在分布外（OOD）场景下的组合泛化能力不足，且捕获可复用技能结构的能力有限。为解决这一局限，我们提出了基于技能的记忆框架（SkillMemo），该框架将长时程演示隐式分解为潜在原子技能，并将技能级特征集成到动态情景记忆库中，以解决组合任务。具体而言，我们首先引入了一个基于混合专家（MoE）架构的专家引导轨迹分割模块，该模块通过学习的门控系数将轨迹隐式划分为不同的技能原语。我们进一步设计了一个技能级情景记忆架构，将紧凑的技能表示存储为可检索的键值对。在推理过程中，记忆库检索最相关的技能原语，并将其与模型当前的门控分布进行融合，为细化动作预测提供强大的上下文先验。在仿真基准和真实世界操作任务上的大量实验表明，SkillMemo能持续增强DP和VLA骨干模型，实现最先进的性能，并超越π_{0.5}，同时对未见过的任务配置展现出强大的组合泛化能力。

## Abstract
Embodied visuomotor models, including Diffusion Policy (DP) and Vision-Language-Action (VLA) models, have demonstrated promising performance on robotic manipulation benchmarks. However, their potential remains fundamentally constrained by the scarcity of large-scale embodied trajectory datasets, leading to insufficient compositional generalization in out-of-distribution (OOD) scenarios with limited capability to capture reusable skill structures. To address this limitation, we propose Skill-Based Memory (SkillMemo) framework that implicitly decomposes long-horizon demonstrations into latent atomic skills and integrates skill-level features into a dynamic episodic memory bank for solving compositional tasks. Specifically, we first introduce an expert-guided trajectory segmentation module built upon a Mixture-of-Experts (MoE) architecture, which implicitly partitions trajectories into distinct skill primitives represented by learned gating coefficients. We further design a skill-level episodic memory architecture that stores compact skill representations as retrievable key-value pairs. During inference, the memory bank retrieves the most relevant skill primitives which are subsequently fused with the model's current gating distribution, providing a robust contextual prior to refine action predictions. Extensive experiments on the simulation benchmark and real-world manipulation tasks demonstrate that SkillMemo consistently enhances both DP and VLA backbones, achieving state-of-the-art performance and outperforming $π_{0.5}$, while exhibiting strong compositional generalization to unseen task configurations.

## 2. 方法论

### 2.1 核心思想
SkillMemo 将长时程演示**隐式分解**为潜在原子技能，将技能级特征存入**动态情景记忆库**；推理时检索最相关的历史技能，与当前模型的门控分布融合，形成上下文先验以细化动作预测。

### 2.2 技术细节与关键公式

**（1）专家引导轨迹分割（Expert-Guided Trajectory Segmentation, EGTS）**
- 将完整轨迹 τ = {(x_t, a_t)}_{t=1..T} 隐式分割为 K 个非重叠技能片段 s_k，每段包含时间窗口 [t_start, t_start+L] 内的观测-动作对（式1）。
- 采用 Mixture-of-Experts (MoE) 架构实现隐式分割：包含 N 个专家网络 {E_i} 与门控网络 G，输出为（式2）：
  - y_t = Σ_{i=1..N} g_i(h_t) · E_i(h_t)
  - 每个专家捕获一种局部运动原语，门控权重隐式定义时间上的技能边界。
- 引入基于**部分信息分解（PID）**的协同信息损失（式3）：
  - L_PID = −[ I({A,B}; G) − I(A; G) − I(B; G) ]
  - 促使专家对形成互补、非重叠的技能分工，同时配合负载均衡损失与 top-k 路由防止专家坍缩。

**（2）技能级记忆架构（Skill-Level Memory Architecture, SLMA）**
- **记忆存储**：以键值对形式组织记忆库 M = {(k_m, v_m)}：
  - **键**：对每个技能片段内的潜特征做时间聚合，得到质心特征 k_m = (1/L) Σ h_t（式4）；
  - **值**：存储该片段内完整时间序列的门控权重 v_m = {g(h_t)}_{t∈τ_m}（式5），保留技能的时间动态细节。
- **记忆检索**：推理时计算当前状态特征 q_t 与所有记忆键的余弦相似度（式6）：
  - s(q_t, k_m) = (q_t · k_m) / (‖q_t‖ ‖k_m‖)
  - 取 top-N 最相似条目；通过预设置信度阈值 δ 做**可靠性检查**，仅当检索结果可靠时才进行门控融合。
  - 融合方式（式7）：g′(q_t) = λ g(q_t) + (1−λ)·(1/N)·Σ v_n[t′]，其中 λ 控制记忆干预强度。
- **记忆更新**：采用**动态剪枝策略**（容量上限 M_max = 1000），删除三类低效用记忆：
  - 时间戳最久远的条目；
  - 长期未被检索命中的条目；
  - 检索时持续低于可靠性阈值 δ 的条目。

## 7. 优点

- **细粒度技能记忆**：相比 MemoryVLA 的整体视觉-语义记忆，SkillMemo 存储行为层面的技能级表征（门控分布），粒度更细、可操作性更强。
- **无需额外标注**：技能分解完全由 MoE 路由隐式学习，不依赖人工标注的技能边界。
- **强可解释性**：专家激活可视化表明门控峰值与"抓碗""开灶"等语义动作高度对齐，隐式分割具有语义合理性。
- **组合泛化突破**：跨套件零样本结果证明了技能跨任务重组的可行性，为数据稀缺条件下的泛化提供了可行路径。
- **模型无关性**：同一框架可无缝适配 DP 与多种 VLA 骨干（UniAct、UniVLA、π0.5），通用性较强。
- **动态记忆管理**：有限容量下的三重剪枝策略兼顾了记忆多样性与质量，具备终身学习潜力。

## 8. 不足与局限

- **实验覆盖不全**：真实世界实验仅使用 DP 骨干，未验证 VLA 骨干在物理机器人上的表现；消融实验未覆盖真实场景。
- **阈值敏感性风险**：可靠性阈值 δ 为固定超参，其对不同任务、不同骨干的敏感度未充分分析，实际部署时可能需要人工调参。
- **推理开销**：专家数量增多时推理时间显著增加（N=10 时约 8s），对实时性要求高的应用构成瓶颈。
