## 摘要
联合嵌入预测架构通过预测缺失观测的潜在表示进行学习，然而许多掩码JEPA主要通过其产生的编码器进行评估。我们探究了一个经过训练的预测通路本身，当原生3D场景中缺失整个实体时，它会推断出什么。我们引入了SR-JEPA，一种针对场景级点云的点原生JEPA，其原始冻结的预测通路可以在给定位置被查询。在评估时，一个物体的每个点在编码前都会被移除，并由位于其质心的32点无形状查询替代。训练仅使用自包含的3D EMA目标：无需重建、语义标签、语言或提升的2D特征。在5,953个留出的ARKitScenes物体上，插补潜在状态达到43.13%的语义身份宏观准确率，比最强的下限高出22.18个百分点。随机化预测路径会移除9.78个百分点，而替换匹配的供体上下文会移除21.98个百分点。在8,570个Sr3D支持对上，完整潜在状态达到41.15 AP；从缺失物体潜在状态解码的身份结合锚点身份和几何信息达到39.37 AP，留下了未解决的1.78个百分点残差。这些结果揭示了一种可查询、可组合的3D预测状态：模型完成了依赖于上下文的实体内容，下游计算将其与度量几何相结合。

## Abstract
Joint-embedding predictive architectures learn by predicting latent representations of missing observations, yet many masked JEPAs are evaluated primarily through the encoders they produce. We ask what a trained predictive pathway itself infers when an entire entity is absent from a native 3D scene. We introduce SR-JEPA, a point-native JEPA for scene-scale point clouds whose original frozen predictive pathway can be queried at a supplied location. At evaluation, every point of one object is removed before encoding and replaced by the same shape-free 32-point query at its centroid. Training uses only self-contained 3D EMA targets: no reconstruction, semantic labels, language, or lifted 2D features. On 5,953 held-out ARKitScenes objects, the imputed latent reaches 43.13% semantic-identity macro accuracy, 22.18 points above the strongest floor. Randomizing the prediction path removes 9.78 points, while substituting matched donor context removes 21.98 points. On 8,570 Sr3D support pairs, the full latent reaches 41.15 AP; identity decoded from the missing-object latent, combined with anchor identity and geometry, reaches 39.37 AP, leaving an unresolved 1.78-point residual. These results reveal a queryable, compositional 3D predictive state: the model completes context-dependent entity content, which downstream computation combines with metric geometry.

## 2. 方法论

### 核心思想
SR-JEPA 是一种点原生（point-native）的 JEPA，在场景级点云上学习**预测潜在状态**。与传统重建式自编码不同，它通过预测可见上下文中缺失位置的 EMA 目标编码器表示来学习，完全不需要重建、语义标签、语言嵌入或提升的 2D 特征。

### 关键设计
- **整体架构**：
  - **上下文编码器**：Point Transformer V3（PT-v3m2），五阶段，深度 (3,3,3,12,3)，宽度 (48,96,192,384,512)，多级特征上采样拼接后得到 **1232 维**逐点状态。
  - **目标编码器**：与上下文编码器同架构，通过 EMA（动量从 0.994 线性增至 1.0）更新，不接收梯度。
  - **预测器**：较窄的六块稀疏 PT-v3，宽度 192，六注意力头；输入/输出投影分别为 1232→192、192→1232；通过**可学习的掩码 token** 在查询位置请求缺失状态。
- **训练目标**：
  - 五阶段 L1 潜在预测损失，各阶段等权（避免浅层/深层失衡）。
  - 额外以 λ=0.1 预测可见上下文 token，提升稠密预测能力。
  - 全部目标均由 3D EMA 编码器从原生点云生成，无外部监督。
- **掩码策略**：仅在**占用三维网格区域**内采样连续立方体掩码，避免浪费计算在空体素上；掩码块大小与比例在训练中从 0.1m/30% 逐渐升温至 0.4m/70%。
- **评估协议（Deletion-first prediction）**：
  - 在编码前完整删除目标物体的所有点，仅保留**固定 32 点、半径 0.15m 的球形模板查询**置于标注质心处（该查询不含类别、尺寸、朝向、轮廓等任何线索）。
  - 冻结整个预训练通路，仅训练一个轻量 MLP 探针读取预测潜在。
  - 计算接口分为三个层面：enc-cut（可见编码器状态）、emb-cut（1232→192 映射）、pred-cut（预测器输出，即本研究的主评估对象）。

## 6. 主要结论与发现

1. **语义身份补全有效且非平凡**：外部 ARKitScenes 上，插补潜在达到 **43.13%** 宏准确率，比最强随机基线（20.95%）高出 **22.18 点**；且跨两个训练配方稳定（单级配方 44.61%）。
2. **预测路径本身有实质贡献**：随机化预测器造成 **9.78 点**下降，证明并非仅靠编码器或随机特征。
3. **预测状态依赖正确场景**：用匹配供体场景替换上下文导致 **21.98 点**下降（从 32.94% 到 10.95%），说明补全内容确实来自对目标周围环境的理解。
4. **组合式分解**：真实身份几何联合 oracle 43.63 点略高于完整潜在（41.15），但差异不显著；用预测身份替换真实身份后仍达 39.37 点，与完整潜力的残差仅 **1.78 点**（置信区间跨越零）。这说明支撑推理大部分可由“补全实体身份 + 锚点身份 + 度量几何”组合得出，关系并非必须被显式编码在状态中。
5. **分工清晰**：预测通路负责“补全什么”（实体内容），度量几何负责“在哪里”，下游计算负责“如何组合”——形成可组合的空间状态基元。

## 7. 优点（方法/实验亮点）

- **提出“删除-优先，固定查询”的评估协议**：将物体发现与状态补全解耦，清晰聚焦于“预测器推断了什么”这一核心问题。
- **点原生、自包含的自监督目标**：无需 2D 基础模型特征、语言或语义标注即可学到可用的缺失实体状态，工程可复现性强。
- **高层级控制逻辑严谨**：
  - 随机化预测器 → 隔离预测路径的训练贡献；
  - 匹配供体场景（union-hole 构造）→ 防止分类器通过删除边界形状区分实验臂，给出令人信服的上下文归因；
  - 联合身份几何 oracle → 判断支撑推理的本质输入；
  - 跨检查点 + 跨配方复现 → 降低单次训练运气的影响。
- **社区价值**：将研究视线从“编码器排行榜”拉回到“预测器作为状态接口”，为后续 JEPA/世界模型研究提供了可量化的评估范式。

## 8. 不足与局限

- **结构与经验范围有限**：
  - Sr3D 支撑端点仅 152 个正样本，正负比例极端，且不区分“支撑者/被支撑者”方向；关系类别也只有 support 一个家族（其他空间关系因坐标预筛选不达标被排除）。
  - 数据集仅室内静态场景，且 Sr3D 与预训练共用 ScanNet 语料源。
- **空间作用范围不明确**：1.5m 邻域诊断因覆盖率不足无法推断，3.0m 因 token 上限不可行，因此“上下文依赖”是否具有房间尺度的全局性并未证实。
- **受控性中的残余偏差**：
  - 单物体删除仍可能留下边界线索；供体配对虽等化了孔洞几何，但仍不能完全排除伪影性特征。
  - 支撑端点的随机预测器移植和供体替换在 AP 上的差值是“描述性”而非可加因果分解。
- **算力未披露**：无法判断训练成本的可扩展性。
- **方法能力边界**：确定性单结果（L1 平均）、静态状态（无时间转移）、需要给定质心（不做目标发现与定位），不能直接外推到动作条件、规划、多假设推断等场景。
