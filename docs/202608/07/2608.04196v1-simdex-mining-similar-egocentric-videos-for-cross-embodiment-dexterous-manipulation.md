## 摘要
近年来，扩展自我中心人类视频用于机器人操作的趋势日益显著，但哪些数据真正有益于灵巧操作仍不明确。我们提出了SiMDex，一种基于相似性的数据挖掘框架，将灵巧操作中VLA后训练的人类数据选择视为推荐问题。对于每条机器人演示，SiMDex采用三层召回-排序-重排序流程，从约3200万自我中心人类样本池中提取任务相关子集， operates in a morphology-agnostic action space that requires no changes to VLA architecture or training. 与使用等量随机采样人类数据的强基线相比，SiMDex仅使用约149万挖掘样本（占样本池的不到5%），却将整体成功率从47.7%提升至61.1%，表明选择性筛选优于不加区分的数据混合。

## Abstract
Recent years have witnessed an explosive trend of scaling ego-centric human videos for robot manipulation, yet it remains unclear which data actually benefits dexterous manipulation. We present SiMDex, a similarity-based data mining framework that casts human data selection for VLA post-training in dexterous manipulation as a recommendation problem. For each robot demonstration, SiMDex employs a three-layer recall-ranking-re-ranking pipeline to extract task-relevant subsets from a pool of ~32M egocentric human samples, operating in a morphology-agnostic action space that requires no changes to VLA architecture or training. Against a strong baseline trained with an equal amount of randomly sampled human data, SiMDex uses only ~1.49M mined samples (<5% of the pool) yet improves the overall success rate from 47.7% to 61.1%, showing that selective curation outperforms indiscriminate data mixing.

- **核心洞察**：针对VLA后训练阶段，从数十亿级（此处为数千万级）人类样本库中按任务感知方式检索与每条机器人演示在动作层面细粒度相似的数据，可以显著提升灵巧操作性能。论文将这一数据选择问题类比为大规模推荐系统问题，提出了SiMDex框架。

### 2. 论文提出的方法论

#### 2.1 核心思想

SiMDex将VLA后训练中的人类数据选择问题**重构为推荐系统问题**：机器人演示为"锚点"，大规模人类样本池为"目标"，通过三层级联（召回→排序→重排序）逐步浓缩出任务相关的数据子集。整个流程在**形态无关的动作空间**中运行，不改变VLA架构或训练过程。

#### 2.2 关键设计：统一的形态无关表示

- 采用**指尖中心几何表示**，抽象掉机器人与人手之间的形态差异。
- **腕部局部重定向（Wrist-local retargeting）**：
  - 关键公式：$q^{loc}_t = T_t^{-1} q_t \in \mathbb{R}^3$（将世界坐标系下的指尖位置转为腕部局部坐标）
  - 腕部动作 $d_t \in \mathbb{R}^6$ 为当前腕部坐标系中的局部增量（平移：$R_t^\top(o_{t+1} - o_t)$；旋转：$R_t^\top R_{t+1}$）
- **共享动作空间**：每时间步的共享动作拼接左右腕部增量与指尖状态，$a_t = (d^L_t, d^R_t, p^L_t, p^R_t) \in \mathbb{R}^{42}$。该表示对工作空间位置不变，且无需跨具身运动学结构匹配。
- 人类数据来自EgoDex数据集（含追踪的腕部和指尖变换），经过身体中心坐标系变换、可见性/速度过滤和时间平滑后，与机器人数据映射到同一表示。

#### 2.3 三层数据挖掘流水线

- **Stage I：召回（Recall）**——从3200万样本中广泛检索候选集
  - **姿态相似性**：将初始指尖状态 $\ell_2$ 归一化为15维描述子，按欧氏距离检索最近邻
  - **语言相似性**：将指令编码为384维句嵌入，按余弦相似度检索
  - 两种排名通过**秩融合（rank fusion）** 合并产生候选集
- **Stage II：排序（Ranking）**——按细粒度运动相似性精排
  - 四个互补组件：腕部平移波形、腕部旋转波形（紧凑速度剖面捕捉运动节奏）、手指轨迹 $F_{fg} \in \mathbb{R}^{30 \times 15}$、腕部轨迹 $F_{ee} \in \mathbb{R}^{31 \times 3}$（保留空间结构）
  - 融合分数 $r = r_{tr} + r_{rot} + r_{fg} + r_{ee}$
  - **轨迹级去重**（去除重复来源片段，保留最高排名条目）后的输出即为用于VLA训练的数据子集 $D^*_h$
- **Stage III：重排序（Re-ranking）**——光流实现与具身无关的视觉验证
  - 光流捕捉像素级运动模式，独立于手部形态
  - 聚合密集光流为片段级描述子，按描述子相似度重新评分
  - 该信号不受重定向精度影响

#### 2.4 VLA训练与跨具身监督

- 基础模型为**π0-like flow-matching VLA**（以GR-Dexter为具体实现），动作解码器预测 $H=30$ 步的动作块 $a_{t:t+H} \in \mathbb{R}^{H \times 88}$
- **跨具身监督**：88维动作空间 = 42维共享维度 + 46维机器人特定维度（手臂和手部关节动作）
  - 机器人样本在所有88维上监督；人类样本仅在42维共享维度上监督，机器人特定维度用占位符填充并通过二进制掩码 $m \in \{0,1\}^{88}$ 排除
- **训练目标**（flow-matching loss）：
  - $$L = \frac{\sum_{h,d} m_{h,d} (\hat{u}_{\tau,h,d} - u_{\tau,h,d})^2}{\sum_{h,d} m_{h,d}}$$
  - 掩码机制使人类与机器人数据可在不修改架构的前提下联合训练单个模型

### 6. 论文的主要结论与发现

1. **选择性挖掘优于盲目混合**：使用约149万挖掘样本（<5%样本池），整体成功率从47.7%提升至61.1%（+13.4）。
2. **任务间的显著差异**：
   - **Flick Wheel**：成功率近乎翻倍（24.5→45.5，+21.0），基线几乎完全无法完成"旋转"（0.13）和"拨出"（0.00）阶段，说明挖掘数据传递了随机数据无法提供的细粒度手指技能。
   - **Pick & Place**：成功率大幅提升（54.0→83.4，+29.4），四个物体上均有稳定增益，体现更强的跨物体形状泛化。
   - **Drill**（钻头任务）：SiMDex略低于基线（54.5 vs 64.5），方差较大；数据扩展消融揭示了原因——当机器人数据充足时，池中稀少的钻孔人类样本反而引入方差；当机器人数据稀缺时，SiMDex仍有益。
3. **低机器人数据场景下的稳定性能下限**：SiMDex从0.5×到2×保持约57-58%的稳定成功率，基线在数据缩减时从50.9%跌至40.9%。最大增益（+17.2）出现在0.5×规模。
4. **实际效率提升**：约6小时机器人演示（0.5×）配合SiMDex挖掘数据，可匹配基线约25小时（2×）的效果——**机器人数据采集量可缩减4倍**。
5. **各阶段互补性**：召回层匹配粗粒度线索，排序层对齐细粒度运动，重排序层通过光流解决运动学匹配可能出现的"运动值相同但视觉本质不同"问题。

### 7. 优点

1. **问题建模新视角**：将人类数据选择重新定义为推荐问题，借鉴大规模推荐系统的"召回→排序→重排序"范式来处理数千万级样本池，方法直观且可扩展。
2. **模型无关性**：仅改变数据来源，不触碰VLA架构或训练过程——这使SiMDex可应用于任何VLA流水线，实用价值高。
3. **形态无关设计**：通过腕部局部指尖表示和掩码监督，优雅地桥接跨具身动作空间，无需复杂的具身对齐模块。
4. **"数据复利"思维**：重新挖掘预训练使用的同一语料库（使之任务感知化），使大规模数据集采集"一次投入、两次收益"（广度和精度各一次），避免了重复采集新数据的成本。
5. **实验设计公平**：基线与方法仅差数据选择方式，隔离了变量；数据扩展消融覆盖了实际部署中最关心的低数据预算场景。
6. **定位清晰**：在数据贫乏的真实场景下，用挖掘的人类数据弥补稀缺的机器人数据，将效果提升体现在真实的成功率上而非仿真指标。
7. **验证细致**：在涉及高自由度灵巧手、真实世界操作的任务中，能取得较大增益，说明方法在复杂场景下有实际价值。

### 8. 不足与局限

1. **场景与任务覆盖有限**：机器人数据仅覆盖单一场景（工业装配），三个任务、约12.4小时演示；跨场景、跨任务、跨具身的泛化性未经验证。
2. **依赖人类样本池覆盖度**：SiMDex的效果**高度受限于人类样本池中是否含有与目标任务质量相近的样本**。Drill任务的结果即是证明——当池中高质量相似样本缺失时，检索难以提供有效信号，甚至在机器人数据充足时还会注入方差。
3. **纯运动学表示的信息瓶颈**：相似度只在运动学动作空间（腕部6D位姿+指尖位置）中度量，**不包含接触力、物体状态或交互语义**。排序阶段可能出现"手几乎不动的钻孔片段被检索到"等误匹配，重排序通过光流修正却需要不小的计算开销。
4. **离线、一次性检索的局限**：什么数据被检索在训练开始前就已固定，无法根据策略训练过程中的失败模式和技能掌握程度动态调整。论文在展望中承认，最优数据依赖于机器人数据量以及策略还缺什么技能。
