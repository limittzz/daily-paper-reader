## 摘要
扩散策略是连续控制中一种强大的策略类别，但其迭代去噪过程造成了 substantial 的计算瓶颈。为降低成本，需要根据每个动作的难度调整去噪步数，同时保持任务性能。我们引入了前缀最优生成策略（POGP），该框架通过去噪链上的贝尔曼式递归，在每一个中间去噪步骤学习一个前缀价值函数。该前缀价值函数有两个用途：它提供了一个辅助训练目标，鼓励中间输出成为高质量的动作；同时，它实现了一种测试时的停止规则，当额外的步骤不太可能产生有意义的改进时，可以终止去噪过程。在四个 MuJoCo 环境中，以及与 12 个基线的比较中，POGP 将所需的去噪迭代次数减少了约 2.7 倍，同时保持了接近完整的任务性能。与最先进的动态扩散基线相比，前缀训练还将最终任务性能提高了约 3.5%。这些结果表明，监督中间去噪步骤不仅对自适应提前停止有用，而且作为改善学习策略的辅助目标也很有用。

## Abstract
Diffusion policies are a powerful policy class for continuous control, but their iterative denoising process creates a substantial computational bottleneck. Reducing this cost requires adapting the number of denoising steps to the difficulty of each action while preserving task performance. We introduce Prefix-Optimal Generative Policies (POGP), a framework that learns a prefix value function at every intermediate denoising step through a Bellman-style recursion over the denoising chain. The prefix value function serves two purposes: it provides an auxiliary training objective that encourages intermediate outputs to become high-quality actions, and it enables a test-time stopping rule that terminates denoising when additional steps are unlikely to produce meaningful improvement. Across four MuJoCo environments and comparisons with 12 baselines, POGP reduces the required number of denoising iterations by approximately 2.7-fold while retaining near-full task performance. Compared with state-of-the-art dynamic diffusion baselines, prefix training also improves final task performance by approximately 3.5%. These results indicate that supervising intermediate denoising steps is useful not only for adaptive early stopping, but also as an auxiliary objective that improves the learned policy.

## 1. 核心问题与整体含义（研究动机与背景）
- 扩散策略（Diffusion Policies）在连续控制与机器人学习中表现出色，能建模多模态动作分布，但其动作生成依赖一条 K 步迭代去噪链（K 次网络前向计算），推理计算开销大，成为实际部署（尤其边缘设备）的主要瓶颈。
- 现有扩散策略框架对所有动作一律使用相同数量的去噪步数，不区分动作难度。然而，真实任务中许多动作是常规的，很快就能确定；少数动作（如接触丰富的转换、扰动恢复、模式切换）需要更多精炼步骤。
- 已有高效/动态扩散方法（如 D3P）通过额外训练一个独立的深度预测/适配器来决定提前停止，但其训练与中间动作质量解耦，且扩散策略本身只优化最终输出的动作，中间步骤没有监督，导致中间动作不可执行，难以支持真正的动态停止。
- 因此，本文提出核心问题：如何在扩散策略中“学习何时停止”，使中间步骤本身具备高质量与可执行性，同时实现自适应计算分配，兼顾最终性能与推理效率。

## 2. 方法论（核心思想、关键技术细节）
- **总体思想**：联合训练一个**前缀价值函数（PVF）**，对去噪链中每个中间动作给出价值评估，既作为辅助训练目标改善中间动作质量，又提供测试时自适应停止信号。
- **核心概念——前缀价值（Prefix Value）**：
  - 对状态 *s* 和中间动作 *a_t*（t=K 为噪声，t=0 为完全去噪动作），定义 *V_t(s, a_t) = Q(s, π_full(s, a_t))*，即“若从该中间动作继续完成整条去噪链，最终动作的期望回报”。
  - 该定义直观回答了“当前部分去噪结果有多有希望”。
- **前缀贝尔曼递归（Prefix Bellman Recursion）**：
  - 利用去噪过程的时序结构，建立相邻步骤的递归关系：
    - *V_t(s, a_t) = h · Q(s, a_0) + (1−h) · V_{t−1}(s, π_θ(s, a_t, t))*，
    - 边界条件 *V_0(s, a_0) = Q(s, a_0)*。
  - 其中 *h* 为均匀危险率（本文取 *h = 1/K = 0.05* 或 0.1，视 K 而定）。
  - 该递归允许用单条共享链生成所有目标的训练数据，避免了每个前缀逐一完整 rollout 的 O(K²) 高成本。
  - 理论证明：该 Hazard Bellman 算子为 ℓ∞ 压缩映射，存在唯一不动点，保证训练稳定。
- **联合优化（三组件）**：
  - 环境 Critic *Q*：标准 double-Q 学习，基于环境转移更新。
  - 前缀 Critic *Vψ*：用上述 TD 目标进行回归，目标中结合最终动作 Q 值与下一级前缀引导值。
  - 策略 π：采用**门控损失**：
    - *Lπ = −E[min_i Q_i(s, a_0)] + w(n)·(−E[Vψ(s, a_{t−1}, t−1)])*。
    - 门控调度：训练初期置信门关闭（w=0），直到 V 的 RMSE 低于阈值 τ 才开启；开启后通过余弦调度逐步升到 w_max。该机制避免早期不稳定的 V 梯度干扰策略。
  - 关键工程细节：共享链（同一噪声样本生成 a_0 与 a_{t−1}）确保梯度对齐、降低方差；移除共享链会显著降低性能。
- **测试时动态停止规则**：
  - 计算连续两步前缀价值之差：*Δ_t = Vψ(s, a_{t−1}, t−1) − Vψ(s, a_t, t)*。
  - 当 *Δ_t ≤ ε·|Vψ(s, a_t, t)|* 连续 *m* 步时，停止去噪。本文设 ε=0.01，m=2。
  - 该规则无需额外训练的停止网络，价值函数本身提供停止信号。
- **完成映射（Completion Map）**：
  - 提前停止后，中间动作 *a_t* 仍含残差噪声，使用一个轻量单层 MLP *gω(s, a_T, T)* 将其投影到接近完全去噪动作 *a_0*。
  - 训练时从均匀分布采样截断步数 T，最小化 *‖gω(s, a_T, T) − a0‖²*。
  - 理论上给出性能差距的界：*LQ · E_T[ε_g(T)] / (1−γ)*。

## 3. 实验设计（数据集/场景、基准、对比方法）
- **环境**：4 个 MuJoCo 连续控制环境——HalfCheetah-v4、Walker2d-v4、Hopper-v4、Ant-v4（动作维度 3–8），使用密集奖励的移动/能量回报。
- **对比基线（12 个）**：
  - 经典 RL 方法：TD3、SAC、PPO。
  - 扩散策略类：Diffusion-QL、DPPO、D2PPO、SDAC、DSAC-D（每个 20 步）。
  - 动态扩散策略：D3P（与 POGP 直接对比，支持提前停止）。
  - 离线-在线方法：IDQL。
  - 生成/多模态方法：FQL、SAC-GMM。
- **评价指标**：
  - 全链性能：20 步去噪下的回报，按环境归一化后计算 IQM（四分位均值，95% 置信区间）。
  - 动态停止性能：平均去噪步数、相对 POGP 全链回报的保留率（Ret.）、速度提升倍数（Spd. = 20/平均步数）。
  - 截断压力测试（T=2、5、10、15）、消融实验、危险鲁棒性测试等。

## 6. 主要结论与发现
- **全链性能提升**：POGP 在 20 步全链下所有四个环境均优于全部 12 个基线，IQM 达 0.942（95% CI: 0.91–0.97），比最佳基线（SDAC）平均提高约 4.6%。
- **动态计算显著节省**：自适应停止时，POGP 平均使用 6.8–8.6 步（视环境），相比固定 20 步链减少约 66%（约 2.7× 加速），同时保留 98–99% 的自身全链性能。
- **对 D3P 的对比优势**：POGP 所需迭代数比 D3P 少 18.2%，最终性能高约 3.5%。
- **扰动应变能力**：在 HalfCheetah 中，受到外力扰动时 POGP 自动将去噪步数从 3–5 提升到 15–20；扰动消除后回到低步数，而 D3P 对扰动反应弱且常态步数高（模式为 9 vs POGP 模式为 4）。
- **消融揭示关键设计**：共享链机制是最关键的稳定性组件；前缀监督可显著提高截断保留率（如 T=5 时从约 82% 提升到 99%）；门控与余弦预热缺一不可。
- **结论**：监督中间去噪步骤不仅实现自适应早停，还作为有价值的辅助目标提升最终策略质量。

## 7. 优点（方法或实验设计亮点）
- **新颖且统一的理论框架**：将动态计算问题形式化为去噪链上的前缀价值函数，使用贝尔曼递归进行高效信用分配，具备压缩映射理论保证。
- **一石二鸟**：同一个价值函数同时提供辅助训练目标和测试时停止标准，无需额外学习停止网络，是一种优雅的联合设计。
- **工程稳定性措施完备**：共享链降低梯度方差、置信门控防止早期噪声梯度、余弦预热平滑引入辅助目标、完成映射处理残差动作，这些设计均有消融验证。
- **实验严谨且有洞察**：对照多种类型基线（经典、扩散、动态、离线、生成）；提供扰动可视化、步数分布、价值校准（Spearman 相关）、完成误差理论界与实验验证等，分析深入。
- **可解释性与泛化**：停止标准基于期望回报增益，有明确语义；对未见过的测试时危险分布仍保持 97% 以上的截断保留率（危险鲁棒性实验）。
- **理论与实践结合好**：给出性能差距界（Lipschitz 常数与完成误差），并验证 O(√T) 的完成误差增长，支撑其停止规则可靠性。

## 8. 不足与局限
- **评测场景有限**：只在四个 MuJoCo 运动控制任务上验证，未包含机器人操作、导航、真实机器人或更高维视觉输入场景；声称的通用性缺乏佐证。
- **链长规模限制**：实验最大 K=20，未验证 K=50/100 的长链；作者指出长链可能需要注意力机制等架构修改，否则前缀反向传播可能不稳定。
- **随机种子敏感性**：1/4 的种子（seed 100）出现门控开启过晚，导致前缀训练收益减小。门控阈值 τ 的鲁棒性需要改进。
- **仅支持确定性去噪器**：方法基准为 DDIM 式确定性去噪；扩展到随机去噪器需修改递归并重新分析压缩率，文中只留作未来工作。
- **完成映射的偏差风险**：在极端早期截断（T=2）时仍能保持较高保留率，但误差随 T 增加，理论界依赖 Lipschitz 常数与完成误差的估计，实际中可能低估最坏情况。
- **计算开销未全面对比**：虽然训练耗时可接受，但 POGP 需要同时训练 Q、V、π、g 四个网络，相比简单基线训练复杂度更高；文中未详细分析每个基线精确的 GPU 小时差异。
